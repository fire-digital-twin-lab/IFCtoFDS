## 2. Phân biệt trạng thái nghiệm thu

| Tầng | Được phép kết luận | Không được suy diễn |
|---|---|---|
| JSON hợp lệ | `result_contract=PASS` | Không suy ra lưới/CFD đã đúng |
| Hash và liên kết tệp hợp lệ | `evidence_integrity=PASS` | Không đồng nghĩa xác minh nguồn IFC độc lập |

## 4. Lệnh chạy kiểm toán tại máy phát triển

Từ thư mục gốc dự án, sau khi cài package theo README:

```powershell
python scripts/audit_job_acceptance.py "DUONG_DAN_THU_MUC_JOB" --mode convert
python scripts/audit_job_acceptance.py "DUONG_DAN_THU_MUC_JOB" --mode scenario
python -m pytest -q tests/test_acceptance_audit.py tests/test_job_evidence_index.py
```

Lệnh kiểm toán không ghi vào thư mục job. Exit code 0 chỉ biểu thị hợp đồng và hash đã kiểm tra được; exit code 2 cho dữ liệu lỗi hoặc thiếu bằng chứng. `preview`/`inventory` được báo `STRUCTURE_VALID` vì không có chỉ mục SHA-256 của workflow convert/scenario, chứ **không được nghiệm thu khoa học**. Luôn kiểm `checks.solver_verification=NOT_RUN` trong kết quả.
